# main 全流程体验复查与修复

本轮延续既有题型、分析和 Skill 改进，检查媒体上传 → 题目设置 → 参与者作答 → 筛选分析 → 导出。范围为本地 main，不涉及 update，也未推送或部署。本记录描述验证到的行为，不代表所有设备、配置和数据规模都已通过验收。

## 本轮完成

- **上传可靠性**：直接上传使用唯一存储名，保留研究者原文件名；同名文件不会互相覆盖。失败文件继续保留供重试，其余文件继续处理。每十个处理文件保存一次清单；清单保存失败停止扩大未保存批次，并提供独立重试入口。修复项目保存接口返回失败却仍显示成功的问题，以及网络恢复后重试仍被旧失败状态阻止的问题。
- **原图选择**：可关闭图片压缩；保留动态 GIF。直接上传单文件上限 40 MB，并记录上传前后字节数及是否转换。刷新媒体列表保留已有文件名与研究元数据。
- **媒体操作**：批量选择、删除、下载、移动和所选图片预标注使用媒体唯一标识。移动保留唯一存储文件名，阻止目标重名覆盖；复制部分失败或项目清单保存失败时不删除源文件。
- **PC 与手机布局**：修复手机上传卡片被长选项撑宽的问题；修复题目预览中 SurveyJS 最小宽度和不换行样式造成的图片、长文件名、选择按钮溢出。PC 保留设置与预览双栏，手机保留分页签与固定底部操作栏。选择按钮至少 44 px 高，文件名保留在无障碍标签中。
- **作答准确性**：视频、音频播放控件不再触发媒体选择，使用明确的选择按钮。补齐媒体选择、评分、是否、矩阵的只读控制；矩阵输入组互相独立并提供行列标签。
- **分享前检查**：显示页数、作答题数、总轮数、空问卷和配置问题，以及尚未保存的修改提示。
- **答卷与分析**：同一参与者的不同提交独立计算质量标记。日期筛选按浏览器本地日历日计算，包含结束日最后一毫秒；启用日期筛选后排除无有效时间戳记录，并明确说明。问卷版本记录补充量表步长、标注约束、注意力检查、选项约束及允许的 Skill 配置字段。
- **可复核导出**：完整分析 ZIP 增加 `responses_raw.json`，保留当前筛选后的原始答卷；CSV 对可能被表格软件执行为公式的文本加前缀，数值和负数保持数值语义。README 解释两种格式的用途。

## 验证

- 前端完整回归：**68 组 / 352 项通过**。
- 媒体流程专项：**9 组 / 44 项通过**（包含在已有测试覆盖内，不额外累加计数）。
- 生产构建通过；仓库现存 ESLint 警告和 Browserslist 数据过期提示仍存在。
- 浏览器检查：390 × 844、1280 × 900。检查媒体页、题目设置、参与者预览、分享和结果空状态；实际点击选择并核对反馈，检查取消时的未保存保护。
- 浏览器仅使用未保存的编辑器草稿，已全部丢弃；没有提交真实答卷、上传文件或执行真实媒体移动/删除。上传、保存失败、重名移动、只读和导出边界由自动化样本验证。

## 尚需独立验收的边界

1. **收集开始后的媒体变更**：当前移动仍改变对象 URL；旧题目与已收集答卷可能保留旧地址。移动前已提示。后续最值得做的改动是研究开始时冻结媒体清单/版本，或引入保持稳定地址的逻辑文件夹；这涉及存储与历史数据兼容，应单独设计，不能仅靠改按钮解决。
2. **预标注历史队列**：本轮把所选图片批量任务改为唯一标识；历史批次审阅队列和部分状态映射仍使用文件名，同名文件的历史审阅状态仍需进一步迁移。
3. **真实设备与规模**：尚未用实体 iPhone/Android、弱网长视频、超大媒体库和大规模答卷做压力验收。窗口尺寸模拟不能代替这些测试。
4. **研究分析适用性**：本轮完善质量筛选、配置溯源和导出，没有增加新的统计推断方法。既有描述统计、排名与一致性方法仍应遵循各自适用条件；不能把重复 trial 当成独立参与者。此前算法和题型匹配修复见同目录审查与修复记录。

当前优先继续补齐数据稳定性和验收样本，无需扩充题型数量或重建 Skill 库。
