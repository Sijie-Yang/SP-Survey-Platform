# main 体验与结果一致性修复

本轮根据 2026-09-09 审查及之前的 PC／手机体验建议修改本地 main。保留已有 Cursor 修改，不涉及 update；未提交、推送或部署。

**结果分析和导出**

- 多轮图片／媒体排序的 long 与 summary 均纳入所有有效轮次。
- 保留逐轮媒体集合、类别、媒体 ID 和来源；旧答卷只能使用题目级上下文时，导出标记为 `question_fallback`，不伪装成精确逐轮信息。
- 同屏多份媒体、一次回答的评分／是否／标签／矩阵／滑杆组／分配题，统一按有序媒体组合统计，一份回答只计一次。
- 媒体来源按完整路径及资源参数区分，移除常见临时签名参数；同名文件不会仅因文件名相同而合并。旧答案只有文件名且无法唯一对应时不猜测。
- 宽表原样保留文字标签和文字排序选项，不再截断 `/` 或 `?`。自定义点标签、路径时间、视频时间段标签在适配与逐题导出中保留。
- 完成比例按提交数计算，另列参与人数与 trial 数；媒体选择率按该媒体的展示轮数计算，导出包含 `exposure_count`。
- 滑杆组按维度计算一致性。同一参与者重复评价相同刺激时，数值观测取均值；冲突的类别重复观测不强行取最后一次。结果说明与 methods.txt 写明规则，summary 补充一致性及预算合规指标。
- 自定义媒体数值题使用数值分布，不再默认为 1–5 评分。
- 筛选偏好仅保存在浏览器，不再调用整份问卷保存。增加筛选重置、范围提示、筛选无结果提示。
- 提交记录可查看每题、每轮答案、展示媒体、质量标记与会话／版本，并分页显示。
- 导出显示处理中状态、阻止重复点击并提示失败；说明宽表、长表和 ZIP 的用途。

**参与者与管理员体验**

- 手机端保留保存、预览、更多三个主要操作；其他工具收进可键盘操作的菜单。侧栏使用覆盖式抽屉，主内容不再被挤出屏幕。
- 一题的多轮任务完成后，优先定位同页尚未完成的任务；仍尊重问卷的最终检查／提交设置。
- 排序题初始顺序不再自动算作回答，可拖动修改或点击“确认当前顺序”。媒体排序可播放音视频。
- 增大手机轮次按钮、收紧页头留白；提前加载下一轮图片，媒体失败时可重试，重试不会误选答案。
- 问卷端继续独立使用管理员设置的参与者语言；本轮复核了用户提供问卷的中文恢复草稿、轮次与导航文案。
- 后台长操作指南默认折叠；路由按需加载。主入口 JS gzip 由此前约 1.01 MB 降至约 190 KB，其他页面代码按需下载；这不是整个问卷页面的总下载量。

**版本与历史数据**

新建参与者会话保存题目答案结构的指纹及必要题目定义，排除集成密钥。恢复草稿优先保留原来的定义；分析单一已知版本或主动选择版本时，使用该版本记录的题目定义。导出 manifest 包含版本和定义。

旧答卷没有记录过的版本、逐轮类别等信息无法追补，界面和导出会标明。未执行数据库迁移，也没有改写历史答卷。分析页仍可选择汇总不同版本，此时会提示版本混合；正式研究分析建议先按版本筛选。

**验证与兼容注意**

- 最终验证：55 个测试套件、286 项测试全部通过；生产构建成功，Worker 打包 dry-run 成功；`git diff --check` 通过。
- 自动回归涵盖多轮汇总、媒体组合、同名来源、资源参数、文本标签、空间／时间字段、分母、筛选不保存问卷、提交详情、排序确认、多轮导航、媒体重试及版本定义。
- 浏览器实测：390px 管理员内容无横向溢出，保存／预览／更多按钮最右边分别为 306／346／382px；390px 参与者双图上下显示，单图约 318×159px，媒体正常加载。1440px 下双图仍并排，单图约 274×137px，无横向溢出。
- 所有检查均未向真实项目提交测试答卷。图表和导出的复杂数据组合由合成样本回归验证；没有把全部题型逐个做一遍真实提交。
- 生产构建保留项目已有的 lint、Browserslist 和 CSS 压缩警告。Worker 只执行打包 dry-run，不发布。
- **导出兼容变化：** 媒体 `unit_key`／`shown_images`／选择值使用完整来源，而非仅文件名；简短名称保留在 `unit_label`。整组媒体的 `unit_key` 是有序来源数组的 JSON 字符串。已有按文件名连接数据的脚本应改用稳定来源，或显式读取显示名称。
