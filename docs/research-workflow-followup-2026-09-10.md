# 科研工作流第二轮完善

本轮在 main 上完善既有流程，没有新增题型或改写 Skill 库，没有推送或部署。承接 `research-workflow-check-2026-09-10.md`，其中“媒体移动仍改变 URL”的边界已由本轮逻辑文件夹改动解决。

## 已实现

1. **媒体归类保持地址**：管理员移动文件或文件夹只更新项目清单里的 `logicalFolder`，保留对象 key、URL、媒体标识及上传元数据。移动回根目录、刷新媒体列表、追加模板导入仍保留分类。批量下载按逻辑目录组织，同名 ZIP 条目自动区分。文件夹标签同步移动；题目的指定文件夹筛选仍需研究者复核，界面已有提示。
2. **按历史定义分析**：收集时保存独立的题目定义副本，包括量表、媒体分配、显示设置及解析后的 Skill 版本和结果结构。正在填写的页面不会因另一个标签页保存设置而突然重建。混合问卷版本默认分开分析；管理员和 Agent/MCP 导出采用相同历史定义。缺少历史定义时显示明确提醒。
3. **设置时看数据格式**：题目编辑器的参与者预览下新增“答案与导出示例”，显示结构示例和真实导出函数生成的列名。PC 保留双栏，手机保留设置/预览分页签。
4. **分享前试运行**：分享页可模拟 1–50 人，使用实际媒体分配和导出函数检查轮次、媒体不足、强制重复和示例答案能否进入长表。可取消、下载报告；设置改变后报告自动失效。模拟答卷仅留在浏览器内存或用户主动下载的文件中，不写入正式结果。
5. **限时媒体交互**：等待媒体就绪、点击开始后才计时，加载失败提供重试。使用截止时间计算剩余秒数，顺序媒体切换新素材后重置到第一项。限时展示提示遵循参与者语言。
6. **导出说明**：管理员与 Agent 的完整分析包新增字段字典和导出配置记录，保留筛选条件、纳入提交标识、提交数和参与者数，说明缺失值与重复轮次的含义。

- Worker 原有专项：9 项通过；生产构建与 Wrangler dry-run 打包通过，未实际部署。构建仍有 ESLint、Browserslist 和依赖 CSS 的 PostCSS 警告。
- 本地浏览器检查：390 × 844 和 1280 × 900；预览、字段说明、分享页试运行，无横向溢出。窗口尺寸已恢复。
- 编辑器测试仅使用未保存草稿，已全部丢弃；没有保存项目、提交正式答卷、上传或移动真实文件。持久化失败和媒体移动边界由模拟测试覆盖。
- 新增样本覆盖历史版本分析、Agent 分析包、模拟分配与导出、限时加载/重试、逻辑目录、下载重名和模板追加导入。

## 明确的适用边界

- 试运行验证配置与数据结构，不执行自定义 HTML、不访问媒体文件，也不验证条件分支、真实回答、播放时长或平衡/自适应算法在真实样本中的效果。这些仍需参与者预览和小规模预实验。
- 历史定义不能倒推尚未记录的信息；逻辑移动也不能修复此前已删除或被覆盖的远端对象。显式删除仍会删除文件。
- 本轮没有新增统计推断方法。字段字典和筛选记录增强复核能力，不保证某种分析适用于所有研究设计；重复 trial 不等于独立参与者。
- 未完成实体 iPhone/Android、弱网长视频或大规模数据压力验收。限时展示不是实验室级精确刺激呈现工具。
- Agent 结果读取原有单次 REST 获取仍依赖服务端返回上限，大规模结果的分页完整性需要后续专门完善。本轮测试样本不构成大规模导出验收。
